비용 0원으로 내 구글 드라이브에 실시간 백업합니다. 시트 화면에 학생별 요약 표와 백업 시각도 함께 기록됩니다.

📖 3분 만에 내 구글 스프레드시트 연동하는 방법 (클릭)
1. PC에서 Google 스프레드시트 새 문서를 하나 만듭니다.
2. 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
3. 기존 코드를 지우고 아래 [스크립트 코드 복사] 버튼을 눌러 붙여넣은 뒤 저장(💾)합니다.
4. 우측 상단 [배포] → [새 배포] 클릭 → 유형을 '웹 앱'으로 선택 → 다음 사용자로 실행: '나', 액세스 권한: '모든 사용자'로 설정 후 배포합니다.
5. 발급된 웹 앱 URL(`.../exec`)을 복사해 위 입력 칸에 붙여넣고 [설정 저장]을 누르면 끝입니다! (코드를 수정했을 때는 반드시 [새 배포]로 새 URL을 발급받아야 반영됩니다.)
