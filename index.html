AI가 선생님의 문체와 구성을 참고할 수 있도록 실제 보냈던 피드백 예시를 등록해 두는 곳입니다.

⚙️ 프로필 설정 및 구글 드라이브 연동

☁️ 구글 스프레드시트(Apps Script) 자동 저장 연동

비용 0원으로 내 구글 드라이브에 실시간 백업합니다. 아래 웹 앱 URL을 입력해 두면 수업을 누를 때마다 자동으로 내 시트에 저장됩니다.

📖 3분 만에 내 구글 스프레드시트 연동하는 방법 (클릭)
1. PC에서 Google 스프레드시트 새 문서를 하나 만듭니다.
2. 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
3. 기존 코드를 지우고 아래 [스크립트 코드 복사] 버튼을 눌러 붙여넣은 뒤 저장(💾)합니다.
4. 우측 상단 [배포] → [새 배포] 클릭 → 유형을 '웹 앱'으로 선택 → 액세스 권한을 '모든 사용자'로 설정 후 배포합니다.
5. 발급된 웹 앱 URL을 복사해 위 입력 칸에 붙여넣으면 끝입니다!
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); sheet.getRange("A1").setValue(e.postData.contents); return ContentService.createTextOutput("OK"); } function doGet() { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = sheet.getRange("A1").getValue(); return ContentService.createTextOutput(data).setMimeType(ContentService.MimeType.JSON); }
